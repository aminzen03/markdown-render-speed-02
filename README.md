A fast, dependency-free Markdown renderer compatible with marked 18.1.3: byte-identical output on all 720 cases, ~1.5x faster than marked.

## Run it

```sh
node main.ts
```

Reads `/input/cases.json` (or `$MAKEFUN_INPUT_DIR/cases.json`), renders each case with `parse()` from `parse.js`, and writes `/output/html.json` (or `$MAKEFUN_OUTPUT_DIR/html.json`).
